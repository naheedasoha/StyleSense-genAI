StyleSense-genAI 👗✨

StyleSense-genAI is an AI-powered fashion and styling project designed to explore personalized style recommendations using Generative AI.

🌟 About the Project

The project aims to make fashion selection easier by helping users explore clothing styles and get personalized styling suggestions.

🎯 Objectives

- Provide personalized fashion and styling suggestions
- Explore the use of Generative AI in fashion
- Create a simple and user-friendly styling experience
- Help users discover styles based on their preferences

🛠️ Technologies

- Python
- Generative AI
- Machine Learning
- AI-based Recommendation
- Web Technologies

📌 Project Status

This project is currently a student project and is being developed as part of my learning journey in AI, Data Science and Generative AI.
